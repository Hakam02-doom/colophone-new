# Colophon image prompt book

For each image: attach the look-and-feel reference, paste the prompt, generate, and save the result to public/images/colophon/ under the 'Save as' name. Any resolution works at the same aspect ratio (larger is better). Then run: python3 tools/gen.py && npm run build. Each image is cropped to its slot and swapped in; images not made yet keep the current picture.
